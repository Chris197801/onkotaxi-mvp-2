# OnkoTaxi MVP 2.0

React/Vite MVP 2.0 z rolami, logowaniem, rejestracją pacjenta, uploadem dokumentów/reklam, panelem admin, kierowcą i mapami.

## Start lokalnie
npm install
npm run dev

## Deploy Vercel
Build command: npm run build
Output: dist
